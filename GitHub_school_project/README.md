# Залікова робота: Програмування

Проєкт для Python 3.11+. Дані у CSV **демонстраційні**, а не дані реальної школи.

## Запуск

```bash
python -m pip install matplotlib
python main.py
```

Запускати з будь-якої папки: шляхи визначаються відносно `main.py`.

## Файли
- `main.py` — обидва сценарії, класи та візуалізація.
- `classes.csv` — паралель і вертикаль класу.
- `students.csv` — учні, клас, ПІБ, рік народження, стать (`Х`/`Д`), оцінка.
- `salaries.csv` — результат розрахунку зарплат.
- `graphs/` — чотири графіки до переведення.
- `output.txt` — приклад фактичного виводу.

## ООП
Інкапсуляція даних у класах `School`, `SchoolClass`, `Student`; успадкування `Employee` → `Director`, `Teacher`, `SecurityGuard`; поліморфізм через `salary()`; композиція: школа містить класи і працівників, клас містить учнів.
